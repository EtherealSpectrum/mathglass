# MathGlass Desktop (Electron) — v3.3.0

Αυτόνομη εφαρμογή επιφάνειας εργασίας για **Windows 11 / macOS / Linux** με:
- **Πραγματική διαφάνεια 0%–100% πάνω από GeoGebra, Επιφάνεια Εργασίας ή οποιοδήποτε πρόγραμμα** (στο 100% φαίνεται καθαρά ό,τι βρίσκεται πίσω από το παράθυρο με ευκρινείς εξισώσεις & κείμενο — χωρίς μη λειτουργικό εφέ θολώματος Desktop)
- **Πάντα στην κορυφή (Pin)** (`Alt+Shift+P`), **Ελαχιστοποίηση** (`Alt+Shift+M`), **Μεγιστοποίηση / Επαναφορά** (`Alt+Shift+F`) & **Κλείσιμο παραθύρου** (`Alt+Shift+Q`)
- **Στρογγυλεμένες γωνίες**, σκιά και **λαβές αλλαγής μεγέθους στις 8 κατευθύνσεις** (όλες οι πλευρές & γωνίες)
- Άμεση **Αντιγραφή** (`Alt+C`) και **Εξαγωγές** (`Alt+Z` — PNG, PDF, SVG, LaTeX, MathML, BBCode) για χρήση σε GeoGebra, έγγραφα και φόρουμ
- Υποστήριξη **`Ctrl+W`** (και `Alt+W`) για άμεση Επεξεργασία στη Λειτουργία Ανάγνωσης
- Υποστήριξη **`Alt+5`** για κλείδωμα της ζωντανής προεπισκόπησης (*Ακολούθηση* ↔ *Σταθερή*)

## Εκκίνηση σε Ανάπτυξη
1. Αποσυμπίεσε ολόκληρο το αρχείο του MathGlass ώστε ο φάκελος `desktop/` να βρίσκεται δίπλα στο `popup.html` (και στους φακέλους `css/`, `js/`, `lib/`, `icons/`).
2. Άνοιξε τερματικό μέσα στον φάκελο `desktop/`:
```bash
npm install
npm start
```

## Δημιουργία Release (Εκτελέσιμο / Installer)
Μέσα από τον φάκελο `desktop/`, μπορείς να δημιουργήσεις πακέτο διανομής (`dist/`) με το `electron-builder`:

```bash
# Για το τρέχον λειτουργικό σύστημα:
npm run dist

# Ή στοχευμένα ανά πλατφόρμα:
npm run dist:win     # Windows (.exe NSIS installer + Portable .exe)
npm run dist:mac     # macOS (.dmg + .zip)
npm run dist:linux   # Linux (.AppImage + .deb)

# Γρήγορο unpacked test build χωρίς installer:
npm run pack
```

Τα τελικά αρχεία Release παράγονται στον φάκελο `desktop/dist/`.
*(Προαιρετικά: για προσαρμοσμένο εικονίδιο installer στα Windows, τοποθέτησε ένα αρχείο `icon.ico` τουλάχιστον 256×256 στον φάκελο `desktop/build/`.)*
